# Domain Documentation

This project uses a **single-context** layout.

## Layout
- **Context**: `CONTEXT.md` at the repository root.
- **ADRs**: `docs/adr/` directory at the repository root.

## Consumer Rules
- Always check `CONTEXT.md` first to understand the project's domain language and core concepts.
- Refer to `docs/adr/` to understand the reasoning behind architectural decisions.
